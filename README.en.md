# RepoScope — GitHub Engineering Intelligence

RepoScope analyzes public GitHub repositories and presents engineering signals such as architecture, technology stack, language composition, and quality criteria. The product includes account registration, a paid subscription flow, and an analysis dashboard.

## Stack
- Next.js and React
- TypeScript
- Stripe subscriptions
- GitHub API

## Run
Install dependencies and start the development server using the scripts declared in `package.json`:

```bash
npm install
npm run dev
```

Configure the environment variables described in `.env.example` before using integrations that require credentials.
